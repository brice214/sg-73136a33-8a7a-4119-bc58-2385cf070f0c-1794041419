## 📄 PAGE 3 — LA SOLUTION MISSU BALA

### Titre section
**Une application citoyenne complète**

### Présentation en 4 modules visuels (cartes arrondies)

#### 📱 Module 1 : Scanner de produits
**Vérification instantanée**
- Scannez le code-barres de n'importe quel produit
- Accédez au registre national AGANOR
- Détectez les contrefaçons en temps réel
- Consultez les informations nutritionnelles (Nutri-Score)
- Identifiez les allergènes et avertissements

*Icône : Code-barres + loupe verte*

#### 📊 Module 2 : Mercuriale officielle
**Prix de référence DGCCRF**
- Consultez les prix plafonds autorisés
- Comparez avec les prix pratiqués
- Recherchez par produit ou catégorie
- Produits de première nécessité
- Mise à jour quotidienne

*Icône : Tableau de prix + étiquette*

#### ⚠️ Module 3 : Dépôt de plaintes
**Signalez les abus en 3 clics**
- **AGASA** : Produits dangereux, périmés, non conformes
- **DGCCRF** : Prix excessifs, pratiques déloyales
- Joignez des photos comme preuves
- Géolocalisation automatique
- Suivi en temps réel de votre dossier

*Icône : Alerte + appareil photo*

#### 📰 Module 4 : Information & actualités
**Restez informé**
- Alertes sanitaires AGASA
- Actualités réglementaires
- Conseils aux consommateurs
- WebTV éducative
- Centre de notifications officielles

*Icône : Journal + cloche de notification*

## 📐 SPÉCIFICATIONS TECHNIQUES POUR LE DESIGNER

### Format & dimensions
- **Format A4 recto-verso** (210 x 297 mm) OU **Dépliant 3 volets** (A4 plié en 3)
- Fonds perdus : +3mm de chaque côté
- Résolution : 300 dpi minimum
- Format livrable : PDF/X-1a pour impression

### Hiérarchie visuelle
1. Titre principal : 36-48pt (Fredoka Bold)
2. Titres de sections : 24-28pt (Fredoka SemiBold)
3. Sous-titres : 18-20pt (Nunito SemiBold)
4. Corps de texte : 11-12pt (Nunito Regular)
5. Légendes : 9-10pt (Nunito Regular)

### Éléments graphiques obligatoires
- Logos institutionnels haute résolution (vectoriel)
- Mockup smartphone Android avec interface MISSU BALA
- Captures d'écran backoffice (anonymisées)
- Icônes personnalisées arrondies (set cohérent)
- Graphiques de données (barres, courbes, camemberts)
- Photos authentiques de marchés/produits gabonais
- QR Code fonctionnel vers Google Play Store
- Badges officiels (Google Play, certifications)

### Accessibilité
- Contraste texte/fond conforme WCAG AA (4.5:1 minimum)
- Taille de police lisible (≥10pt)
- Espacement suffisant entre éléments
- Pas de texte sur images sans fond opaque
- Légendes alternatives pour graphiques

### Ton & langue
- **Français institutionnel** (pas d'anglicismes inutiles)
- Phrases courtes et percutantes
- Vocabulaire accessible au grand public
- Éviter le jargon technique
- Bénéfices avant les fonctionnalités
- Appels à l'action clairs
